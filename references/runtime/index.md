# Managed runtime

Use [`guide.md`](guide.md) for operational procedures covering:

- `dotnet-counters`, `dotnet-trace`, `dotnet-stack`, `dotnet-dump`, `dotnet-gcdump`, and SOS;
- managed CPU sampling and runtime events;
- allocation stacks, GC pauses, promotion, LOH, and pinning;
- JIT, tiering, ReadyToRun, and dynamic PGO;
- exceptions, ThreadPool starvation, locks, async chains, and dumps.

Pair it with the selected [`../platforms/`](../platforms/index.md) guide when native scheduling, kernel, or system ownership matters.
